That works, but it means a brief that omits the instruction silently breaks the learning loop, and the specification's validation hooks were meant to verify memory writes happened. Worth a check once DevOps exists. (noticed 2026-08-10)
- **The CEO cannot create a new agent's memory scaffold** — the brief write grant is globbed to `brief.md` specifically, so `playbook.md` for a new agent cannot be pre-created. New agents must create their own on first run. Acceptable, but it means the first run of every agent has no playbook to read and the brief must say so. (noticed 2026-08-10)
